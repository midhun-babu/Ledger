# Forensic AI Assistant: Dual-Purpose Investigation Platform

The **Forensic AI Assistant** is a local, fully-offline Windows investigation tool powered by AI. It is built for forensic analysts to handle both **Digital Forensics and Incident Response (DFIR)** and **Financial Fraud Investigations** simultaneously. 

By running entirely locally, it ensures 100% data privacy and operational security. No case data ever leaves your machine.

## Core Methodology: "Trust but Verify"

This platform is built on a strict deterministic-first methodology to prevent AI hallucinations. The pipeline operates as follows:

1. **Evidence Ingestion:** 
   Raw digital evidence (EVTX, MFT, Registry) and financial evidence (Bank CSVs) are parsed and normalized into a single, unified timeline stored in a high-performance DuckDB database.
2. **Deterministic Anomaly Detection (Flags):** 
   Before the AI even looks at the data, hardcoded, deterministic rules (such as Benford's Law deviation, Structuring Detection, and Pass-through velocity anomalies) scan the timeline and generate **Anomaly Flags**.
3. **Hypothesis Generation:** 
   The local AI agent reads the timeline and anomaly flags to formulate investigation hypotheses.
4. **Verification & Traceability:** 
   **The AI cannot invent findings.** Every hypothesis must be verified by citing specific, concrete timeline rows or anomaly flags from the database. Any finding generated by the AI is strictly linked back to its source evidence.
5. **Report Output:** 
   The platform compiles confirmed, evidence-backed findings into a structured report ready for human review, including an Evidence Index where every claim is numbered and traceable.

## Key Features

- **Unified Timeline:** Mixes DFIR events and financial transactions in a single chronological view.
- **Financial Anomaly Layer:** Detects structuring, rapid pass-throughs, and dormant account revivals automatically.
- **Evidence Traceability:** The React-based dashboard includes a Trace Panel, allowing reviewers to click any AI finding and immediately see the raw database records that prove it.
- **Structured Reporting:** Generates consultant-ready reports divided into Executive Summary, Methodology, Digital Forensics Findings, Financial Findings, and Evidence Index.

## Project Structure

- **Backend (Python):** A `Typer` CLI for running the pipeline (ingest, analyze, report) and a `FastAPI` server for serving the database to the UI.
- **Frontend (React + Vite):** A modern, dark-themed dashboard to review evidence, filter DFIR vs. Financial events, and track AI insights.

## Getting Started

### Prerequisites

- Python 3.9+
- Node.js & npm
- A local AI model server (e.g., LM Studio or Ollama) running locally and exposing an OpenAI-compatible API.

### Running the Application

You can launch both the Python backend API and the React frontend simultaneously using the included PowerShell script:

```powershell
.\start.ps1
```

### Trying the Demo Case

To see the pipeline in action without real data, use the demo generator to create synthetic bank statements and fake EVTX logs featuring planted anomalies:

```bash
cd backend
python main.py generate-demo C:/cases/demo_case
python main.py analyze C:/cases/demo_case
```

Then point the web UI to `C:/cases/demo_case` to explore the generated timeline and flags.
